# OpenWolf

You have project intelligence data in `.wolf/`. Use it:

1. **Before reading a file**: Check `.wolf/anatomy.md` first for file descriptions and sizes
2. **Before writing**: Check `.wolf/cerebrum.md` for Do-Not-Repeat rules
3. **After fixing a bug**: Use `wolf_log_bug` to log the fix
4. **When corrected**: Use `wolf_learn` to record the correction
5. **Before debugging**: Use `wolf_search_bugs` to check for known fixes
